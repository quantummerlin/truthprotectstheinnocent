## CUSTOMIZATION

### Change Scroll Speed

In `ticker.css`, find `:root` and change:
```css
--ticker-speed: 80s;    /* Faster = lower number, Slower = higher number */
```

### Change Colors

```css
--ticker-bg: #1a1a2e;       /* Background color */
--ticker-text: #ffffff;     /* Text color */
--ticker-accent: #e74c3c;   /* Accent color (author names, separators) */
```

### Change Height

```css
--ticker-height: 60px;
```

## ADDING NEW QUOTES

Open `js/quotes-data.js` and add to the `QUOTES_DATA` array:

```javascript
{
    text: "Your new quote here",
    author: "Name",
    country: "Italy",
    category: "action",  // action, family, corruption, legal, international, personal
    batch: 3,
    rating: "bronze"     // diamond, gold, silver, bronze
}
```

Then update the stats:
```javascript
const QUOTES_STATS = {
    totalComments: 763,  // Add new count
    // ... update other numbers
};
```

## TROUBLESHOOTING

**Ticker not scrolling?**
- Check that CSS animation is loaded
- Make sure `quotes-data.js` loads before `ticker.js`

**Quotes not showing?**
- Check browser console for JavaScript errors
- Verify QUOTES_DATA array is properly formatted

**Want to change the label?**
- Edit the `<div class="ticker-label">PUBLIC VOICE</div>` text
